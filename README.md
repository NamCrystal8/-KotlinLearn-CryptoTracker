# CryptoTracker

A cryptocurrency tracking app built to learn Kotlin and modern Android development.

## Tech Stack

- Kotlin + Jetpack Compose
- Clean Architecture (MVVM)
- Hilt for DI
- Retrofit + Room
- Coroutines & Flow

## Setup

1. Get a free API key from [CoinGecko](https://www.coingecko.com/api)
2. Add to `local.properties`:
   ```
   COINGECKO_API_KEY=your_api_key
   ```
3. Build and run

## Features

- Coin list with prices
- Search & pagination
- Coin detail with chart
- Offline caching
